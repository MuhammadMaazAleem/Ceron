### 4. Key Terms, Definitions & Formulas
- **Base Quantities** (بنیادی مقداریں): Seven fundamental quantities that form the foundation of SI units.
- **Least Count** (کم ترین گنتی (لیسٹ کاؤنٹ)): The smallest value that can be measured accurately by an instrument.

```
Least Count of Vernier Caliper: LC = Smallest Main Scale Division / Total Vernier Divisions = 1 mm / 10 = 0.1 mm
Specifies instrument measuring precision.
```

### 6. Worked Examples

#### Example 1: Zero Error Calculation in Screw Gauge
**Problem:** A screw gauge has 100 circular scale divisions and pitch 0.5 mm. If zero of circular scale is 3 divisions above reference line when jaws are closed, find zero error and zero correction.
**Step-by-Step Solution:**
- **Step 1: Calculate Least Count:** LC = Pitch / Circular Divisions = 0.5 mm / 100 = 0.005 mm.
- **Step 2: Negative Zero Error:** Since zero is above reference line, Zero Error = -(3 × 0.005 mm) = -0.015 mm.
- **Step 3: Zero Correction:** Correction = +0.015 mm (must be added to all observed readings).
**Answer:** `Zero Error = -0.015 mm, Zero Correction = +0.015 mm`


### 7. Common Mistakes & Exam Traps

- ❌ **Mistake:** Subtracting negative zero error instead of adding zero correction.
  ✓ **Correction:** Always apply: Correct Reading = Observed Reading + Zero Correction.
  *Reason: Sign convention must be strictly preserved to avoid systematic error.*
